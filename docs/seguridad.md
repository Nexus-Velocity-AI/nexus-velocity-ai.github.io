# Seguridad

## Principios
- **Fail-closed:** sin secreto, sin firma o sin aprobación, se deniega.
- **Mínimo privilegio y aislamiento:** los servicios internos solo escuchan en la red local; el acceso remoto pasa por un control de identidad.
- **Humano en el circuito** para toda acción con efecto externo.
- **Trazabilidad:** auditorías documentadas, copia previa y plan de reversión para cada cambio, y un monitor de solo lectura.
- **Pruebas automatizadas** de las reglas de seguridad más importantes.

## Lo que este sitio NO publica
Código interno, historial del repositorio privado, flujos de n8n, bases de datos, copias de seguridad, variables de entorno, claves, tokens ni datos de clientes. Se revisó el contenido antes de publicarlo con un escáner de secretos.

## Estado honesto
Es un proyecto personal en modo controlado. No ha sido auditado por un tercero independiente.

# Uso

Nexus Velocity IA **no es un servicio público**: no hay registro de usuarios ni demo abierta.

## Qué puedes hacer hoy
- Leer la [arquitectura](arquitectura.md), la [seguridad](seguridad.md) y el [roadmap](roadmap.md).
- Ver el repositorio de arquitectura del autor: github.com/sdannyandres/nexus-velocity-ia-architecture.
- Contactar para colaborar, dar feedback o apoyar el proyecto: sdannyandres@gmail.com.

## Ver este sitio en local
```bash
python3 -m http.server 8080
```
Abre `http://localhost:8080`.
